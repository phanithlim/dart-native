## Recommended Learning Order

1. **CMake Tutorial** — hands-on introduction to the basics
2. **Modern CMake** — best practices, avoid outdated patterns
3. **vcpkg Getting Started** — quick to set up once you know CMake
4. **vcpkg Package Search** — browse available libraries
